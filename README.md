# 一个音乐小白，和 AI 一起写了人生第一首歌

> 我不会乐器，不懂乐理，但我有哼唱。这就够了。

---

## 我喜欢音乐，但音乐不认识我

我能在一个普通的深夜，因为一首歌的某个段落突然头皮发麻。那种颅内高潮——你知道那种感觉吗？和弦推进到恰到好处的一瞬间，像有人在你后脑勺轻轻推了一把。

但我始终是那个"听的人"。

我有灵感。走在路上，洗澡时，半梦半醒之间，脑子里会突然冒出一段旋律。我只能用手机录下来——一边哼一边怕忘了，像用手捧着一捧水往家里跑。

录完了，然后呢？

我不知道什么是 DAW，不知道和弦进行是什么，不知道一首歌从哼唱到成品中间到底经历了什么。那些教程里密密麻麻的旋钮和术语，对我这种人来说不是知识，是墙。

所以那些灵感就一直躺在手机里。几十段哼唱。像种子没有土。

---

## 转折：AI 不应该替我写歌，它应该教我写歌

后来 AI 来了。

Suno、Udio 这些工具我试过。输入"一首忧伤的流行歌"，30 秒出成品。听起来…还不错。但问题是——那不是我的。

就像一个朋友说"我帮你画了一幅画，你拿着吧"——画得再好，和你有什么关系？

我想要的不是 AI 替我创作。我想要的是：**有人能听懂我的哼唱，然后告诉我，怎么把它变成一首完整的歌。**

这之间的差距，不是一个更好的 AI 模型能解决的。它是一个**协作系统**的问题。

于是我做了一个决定：不找一个"帮我写歌的 AI"，而是找一个"带我写歌的 AI 老师兼助手"。

我选了 Claude Code。

---

## 我不是在"使用"它，我是在和它建立一个创作体系

这件事的起点，是我在一个技术论坛里提了一个很粗糙的问题：

> "我喜欢音乐但不会乐器，想用 AI 创作有灵魂的歌，该怎么办？"

我收到了两篇极其用心的回复——技术方案，从工具选型到编曲方法论，事无巨细。我到现在都不知道回帖的人是谁，但这两篇回复成了我整个体系的基石。

然后我把这两篇回复、加上我自己的想法，一起交给了 Claude Code。我说：

> "这是我的诉求，这是两个方案。请你帮我整合成一个可以执行的起点方案。"

它没有给我一个"答案"。它给了我一个**系统**。

---

## 七步闭环：从"脑子里的一段哼唱"到"可以发给朋友的歌"

这个系统最终被固化为 7 个阶段。每个阶段都遵循同一个原则：**我做审美决策，AI 做技术执行。**

### Phase 0：灵感捕获

不需要任何工具。手机自带录音，文件名格式：`日期_情绪_秒数.mp3`。

关键是——**只记录，不评判**。不要一边录一边想"这段是不是不够好"。灵感不是用来筛选的，是用来攒的。

### Phase 1：灵感解构

选一段哼唱，用比喻描述它——"像雨后的街道"、"像记忆闪回的画面"。

然后 Claude Code 用 Python 脚本分析它的调性、BPM、音域。它告诉我："这段是 G 大调，85 BPM，音域在一个八度内——很适合做 Indie Pop。"

我第一次知道，原来我随口哼的东西，是有"数据"的。

### Phase 2：骨架搭建

把哼唱通过 Basic Pitch（一个免费开源工具）转成 MIDI——把我的声音变成可编辑的音符。

然后 Claude Code 给我推荐和弦进行："你这个旋律偏温暖，I-V-vi-IV（C-G-Am-F）会强化这种感觉。vi-IV-I-V 会更忧伤有力。你想走哪个方向？"

它每次都给我 2-3 个选项，解释情绪差异，让我选。**它从来不说"你应该这样"。**

### Phase 3：结构规划

我们把一首歌想象成一条情绪曲线。

Intro 是"第一印象"，Verse 是"喃喃自语"，Chorus 是"释放"。每个段落的乐器密度不同——歌词写成 `██░░` 这种直观的密度条。

不需要懂五线谱。你只需要回答一个问题：**"这段你想要什么感觉？"**

### Phase 4：编曲配器

这是最大的坎，也是 Claude Code 最闪光的地方。

它教了我一个叫"四层建筑法"的东西——把一首歌想象成盖一栋楼：

| 层 | 作用 | 比喻 |
|----|------|------|
| **地基**（贝斯+鼓） | 让你想踏步 | 楼的地基 |
| **骨架**（钢琴/吉他和弦） | 告诉你歌是开心还是悲伤 | 楼的框架 |
| **血肉**（主旋律） | 让人记住 | 楼的外观 |
| **灵魂**（弦乐/Pad/音效） | 大空间还是私人耳语 | 楼的氛围 |

"现在进副歌。除了主旋律，你觉得需要加什么？"

"加弦乐铺底？还是加鼓？"

"选项 A 是鼓——像走路变跑步。选项 B 是弦乐——像从室内走到开阔广场。你想哪个？"

——**我从来不需要知道怎么操作，我只需要知道我想要什么感觉。**

### Phase 5&6：动态、混音、成品

从"这里太空了"到"这里太满了"，反复调整。最后导出 MP3。

## 最让我感动的一个设计

在这个体系的最开始，Claude Code 让我的项目目录下生成了一个文件：`CLAUDE.md`。

它不是给我用的。它是给 Claude Code 自己用的——一个"角色协议"。

里面写的第一条：

> **"你是音乐创作副驾驶。你不是替代我创作，而是帮我跨越技术门槛。我是导演和决策者，你是技术顾问和选项提供者。"**

AI 自己给自己写了一份约束，确保它**不会越俎代庖**。

而每一首歌，都有一个 `project_log.md`——创作日志。三天后回来，你还能看到三天前为什么选了这个和弦。

这个设计让我意识到：好的 AI 协作，不是 AI 多聪明，而是**人机之间的信息结构**设计得好。

---

## 为什么 Suno 一键生成的歌没有灵魂

因为 AI 的"创作"本质上是在追求**统计学最优解**——最平滑、最标准、最不出错。

而人的创作恰恰相反。最好的音乐瞬间，往往来自**有意的选择**和**美丽的错误**。

那个气息不稳的高音。那个稍微拖延了一点的节拍。那个"理论上是错的但听起来就是对的"和弦。

这些是人的指纹。

在最后导出之前，Claude Code 提醒我："在最终版本中，可以故意保留 1-2 个不完美的瞬间。"

**不完美也可以是一种完美。** 这句话从一个 AI 嘴里说出来，让我觉得它是真的理解了我。

---

## 我在写这段文字的时候，第一首歌还没做完

对。我现在还在 Phase 0：刚装好工具，录了第一段哼唱。

这条路上还有太多东西要学。但我已经感觉不一样了——那些手机里的哼唱录音，不再是"没用的灵感碎片"，而是一个个还没发芽的种子。

我第一次觉得，我和音乐之间，不是我在仰望它。而是我可以**走进去**。

---

## 给和我一样的你

如果你也是一个"有灵感但不会乐器"的人：

1. **不要用 AI 替你创作。** 用 AI 帮你跨越技术门槛。你是导演，AI 是你的执行团队。
2. **从最小的工具开始。** 一个免费 DAW（BandLab 真的够用了），一个哼唱转 MIDI 工具（Basic Pitch），一个愿意和你一起探索的 AI 助手。
3. **完成比完美重要。** 第一首歌的目标是"做出来"，不是"做好"。你的审美永远会超出你的技术——这完全正常。
4. **保留你的指纹。** 你那些不够完美的哼唱、不标准的节奏、不合规矩的旋律——恰恰是你和所有 AI 生成内容之间的唯一区别。
